# LogiHub · 全球物流查询工作台

中文物流工作台，使用 Node.js 22+ 和原生 HTML/CSS/JavaScript，无 npm 安装依赖。

## 本地运行

```sh
cd /workspace/foreign-trade-agent
npm start
```

默认监听 `0.0.0.0:3000`，支持 `PORT`；开发时使用 `npm run dev`。检查命令：`npm run check`、`npm test`（12 项测试）。

## 功能

- 19 家物流商目录：10 家海运、5 家国际快递、4 家双清专线。
- 中英文搜索、分类、收藏；批量添加最多 20 个单号并去重。
- 我的运单支持搜索、复制和移除，目录与运单保存在当前浏览器。
- 页面内查询轨迹与时间线，不再自动打开外部网页。
- 官网查询链接保留为手动备用入口；部分链接可携带单号。

## 实时轨迹：尚待开通

后端 `POST /api/track` 使用 17TRACK API，密钥只从服务端的 `TRACK17_API_KEY` 读取。接口有缓存和限流；前端展示查询中、真实事件、尚无事件及错误状态，不显示模拟运输状态。

**已部署到 https://foreign-trade-agent.onrender.com/ ，并通过用户授权单号完成真实 17TRACK 查询，返回服务商 TZ 和 5 条轨迹。** 同智（TZ）和国际快递可尝试在本页查询；需核对服务商识别结果。其他海运及双清服务商仍未确认覆盖，不保证所有单号都能查到。自动测试使用测试替身，与本次真实单号验证区分。

GitHub Pages 只能托管静态页面，无法运行实时轨迹后端；请使用 Render 地址。页面与 API 已部署到同一 Render 服务，密钥仅在服务端配置。仓库内的 `render.yaml` 用于重复部署。详情见 [API_SETUP.md](API_SETUP.md)。

## 数据与限制

查询时单号会发送到后端及 17TRACK；首次登记可能消耗 API 额度。原始 API 凭据不传前端、不写日志或仓库。轨迹只保留在当前页面内存中。服务商识别与时间线以真实响应为准，未知或未返回的数据不会伪造。

浏览器清理数据会删除运单与收藏，不提供登录或跨设备同步。同智、世达和美特原链接是 HTTP，界面已标注。不要向这些网页提交敏感信息。

验证记录见 [VALIDATION.md](VALIDATION.md)，部署说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。
