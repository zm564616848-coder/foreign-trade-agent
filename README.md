# LogiHub · 全球物流查询入口

使用 Node.js 22+ 和原生 HTML/CSS/JavaScript，无需安装 npm 依赖。线上地址：https://foreign-trade-agent.onrender.com/

## 查询方式

1. 选择物流商，输入一个单号。
2. 点击“打开查询结果”，立即弹出携带单号的新窗口。
3. FedEx、DHL、UPS、USPS 和 17TRACK 使用各自的查询网站；其余物流商使用明确标注的 17TRACK 备用查询。不要将聚合查询标成对应物流商官网。

查询不经过本平台 API，不在本页展示时间线。无需再次复制、粘贴单号。平台只能保证生成含单号的目标链接，外部网站的验证码、地区限制或改版可能影响查询。17TRACK 自动识别，不保证覆盖所有海运或双清单号。

一次查询一个单号，以免浏览器拦截多个自动窗口。允许本站弹出窗口；若被拦截，页面提供含相同单号的重试链接。新窗口断开 opener。目录卡片可选中物流商并直接查询已输入单号。历史运单和收藏保留在当前浏览器中，不提供跨设备同步。

## 运行及验证

```sh
npm start
npm run check
npm test
```

默认监听 `0.0.0.0:3000`，支持 `PORT`。`npm run dev` 开启服务端监听。无构建或安装步骤。自动测试覆盖目录、单号参数、来源标注、聚合回退及服务器。浏览器测试检查单击即开窗、目标单号、新窗口隔离、拦截回退和未调用轨迹 API。

## 旧轨迹接口

用户已选择官网跳转方式，原 `/api/track` 生产默认返回 410，防止继续产生 API 查询或登记费用。旧适配器及其单元测试保留作回归参考，当前页面不使用它们。不再需要 `TRACK17_API_KEY` 来使用查询入口，已有密钥不会输出或放入前端。

查询来源、轨迹与数据由外部网站提供，单号仅随查询链接发给目标网站。
