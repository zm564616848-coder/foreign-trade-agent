# LogiHub · 全球物流查询工作台

一个无需安装运行依赖的中文物流工作台，使用 Node.js 22+ 和原生 HTML/CSS/JavaScript。

## 启动

```sh
cd /workspace/foreign-trade-agent
npm start
```

默认监听 `0.0.0.0:3000`，可以通过 `PORT` 覆盖。开发时使用 `npm run dev` 自动重启服务器。健康检查：`curl -fsS http://127.0.0.1:3000/api/health`。

## 功能和边界

- 汇集用户提供的 19 个官网入口：10 家海运、5 家国际快递、4 家双清专线。
- 支持中英文搜索、分类筛选和星标收藏。
- 一次添加最多 20 个单号，支持换行、空格、逗号和分号分隔，自动去重。
- 我的运单支持搜索、复制、跳转官网和移除；运单和收藏保存在当前浏览器 localStorage。
- 响应式布局、键盘访问和对话框操作。

**当前通过官网查询，不在本页面聚合轨迹。** 输入一个单号并提交后自动打开官网。DHL、UPS、FedEx、USPS 和 17TRACK 的链接会携带单号；其余 14 家打开原查询页，需要复制后粘贴。批量添加时逐条点击查询，避免浏览器拦截多个弹窗。若单个查询窗口被拦截，也可点击弹窗内链接。

未接入官方轨迹 API，也不会伪造运输状态。官网可能改版、限制地区访问或要求验证码，需以官网为准。当前云环境到官网的访问受到网络策略限制，因此未验证官网是否接受参数或展示结果；已验证本平台生成链接、携带单号和新窗口行为。若官网未自动填入，请复制单号手动查询。复制功能要求浏览器允许剪贴板访问，无法自动复制时可选中单号手动复制。

同智、世达和美特的原始链接为 HTTP，界面做了提示。不建议向这些页面提交敏感信息。平台不内嵌第三方网页，不尝试绕过验证码或访问限制。

要在一个页面直接展示所有真实轨迹，需要进一步获得物流商 API 或聚合服务授权，并实现服务端适配、凭据管理和查询限流；本版本无需任何密钥。没有用户登录或跨设备同步，浏览器清理数据后记录会丢失。

## 验证

```sh
npm run check
npm test
```

测试覆盖物流目录、过滤组合、单号校验、静态页面和健康接口。浏览器交互验证另见 `VALIDATION.md`。

仓库没有运行时依赖，不需要 `npm install`，也没有构建步骤。不要将 API 密钥提交到仓库。
