# LogiHub · 物流网站导航

当前版本仅作为物流网站导航，不提供单号查询、自动带单号跳转、轨迹时间线或运单管理。

- 汇集 19 个原网站地址，按海运、国际快递、双清专线分类。
- 支持按物流商名称筛选，以及本地收藏。
- 点击整张物流商卡片访问原网址，不替换成聚合查询，不提交单号。
- 双清网站保留已核验说明；原“世达”网址实际显示广州世拓，集米和美特的品牌归属待核验。见 WEBSITE_VERIFICATION.md。

线上入口：https://zm564616848-coder.github.io/foreign-trade-agent/

## 本地运行

Node.js 22+，无需安装 npm 依赖或构建。运行 `npm start`，默认监听 `0.0.0.0:3000`，支持 `PORT`。检查命令：`npm run check`、`npm test`。

## 数据与旧版本

收藏保存在当前浏览器。取消运单界面没有删除旧浏览器中的记录，收藏写入也会保留旧字段。当前页面没有发送运单的表单、自动弹出查询窗口或调用轨迹接口的代码。旧后端 API 生产默认保持停用（410），不需要 API 密钥。仓库保留的旧适配器和测试仅作为历史回归参考，不是当前用户功能。

原网站内容由各网站维护，部分网址使用 HTTP；平台没有修改浏览器安全保护。
